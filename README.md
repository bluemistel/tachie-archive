# 立ち絵配布アーカイブ索引

https://bluemistel.github.io/tachie-archive/

uploader.jp（getuploader.com）は2026年11月25日に終了予定です。ニコニコ静画で配布されている立ち絵・素材のうち、uploader.jp のリンクを含む作品（約1万件）を一覧で探せるようにした索引です。

- このページは**索引のみ**です。素材ファイルの保存・再配布はしていません。
- 作品タイトル・概要文・投稿者名・タグ・アップローダのURLは、ニコニコ静画で非ログインで公開されている情報です。サムネイルはニコニコ側の画像を直接表示しています。
- リンク先がまだ生きているかは確認していません。各自で元作品とアップローダのリンクを開いて確認してください。
- お気に入りはブラウザ内（localStorage）にだけ保存され、外部には送信されません。

## 構成

- `index.html`：一覧ページ（検索・絞り込み・お気に入り）。サーバー不要の静的ページです。
- `data.json`：作品データ。取得日はページのヘッダーに表示しています。
